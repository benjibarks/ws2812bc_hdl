# IP Repo
Vivado IPs built from the HDL source code of this repository

## IPs

- `ws2812B`: WS2812B driver with an AXI Streaming receiver user interface. Timing values are limited to ranges listed in the WS2812B datasheet
- `ws2812C`: WS2812C driver with an AXI Streaming receiver user interface. Timing values are limited to ranges listed in the WS2812C datasheet
- `led_pattern_emitter_1_0`: On trigger, emits a stream of color data to an AXI Streaming transmitter interface based on an input pattern
